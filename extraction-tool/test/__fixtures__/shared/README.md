# Shared Fixtures

`test/__fixtures__/shared/` contains the base fixture corpus that existed before the fixture layout was categorized by purpose. The files were moved mechanically from the former top-level `document-models/`, `form-models/`, `overview-models/`, and `relationship-models/` directories.

These fixtures preserve their original lineage and content. They are intended for reusable extraction scenarios that are not specific to the new synthetic `products/` or minimal `scdm/` categories.
